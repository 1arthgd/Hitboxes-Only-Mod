# Hitbox Only (Geode mod)

- **H in a level**: toggle hitbox-only mode on/off
- **H in the main menu**: open the settings (color + opacity per hitbox type, show portals, show orbs/pads/coins, fill opacity)

## Build
Option A - GitHub (no local setup):
1. Create a new GitHub repo and push these files.
2. Go to Actions -> "Build Geode Mod" -> Run workflow.
3. Download "Build Output" -> contains yourname.hitbox-only.geode
4. Put the .geode file in your Geometry Dash `geode/mods` folder.

Option B - local: install the Geode CLI + SDK (https://docs.geode-sdk.org/getting-started/),
then run `geode build` in this folder.
